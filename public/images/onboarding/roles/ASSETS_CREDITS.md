# ANEI Onboarding Role Assets — Documentation & Credits

## 1. Overview
All visual assets in `public/images/onboarding/roles/` are bespoke, custom-designed Editorial Vector Illustrations (Option A) created specifically for the ANEI inclusive education platform onboarding flow.

## 2. Palette & Specifications
- **Format**: Clean, self-contained SVG vectors (`viewBox="0 0 160 160"`).
- **ANEI Institutional Palette**:
  - Primary Navy: `#0A192F`
  - Tunisian Azure / Brand Blue: `#0056D2`
  - Institutional Gold: `#C9913F` / `#DFAC56`
  - Neutrals: `#F8FAFC`, `#EFF6FF`, `#CBD5E1`, `#94A3B8`, `#64748B`
  - Role-specific soft tints: Emerald (`#059669`), Amber (`#D97706`), Violet (`#9333EA`), Indigo (`#4F46E5`).

## 3. Role Manifest
1. `role-learner.svg` (`STUDENT`): Adult professional learner with modern laptop, study notes, and diploma scroll.
2. `role-parent.svg` (`PARENT`): Caring parent with school-age child engaged in an inclusive educational activity.
3. `role-teacher.svg` (`TEACHER`): Educator standing near an interactive pedagogical board with PEI and differentiation tools.
4. `role-avs.svg` (`AVS`): School support assistant (AVS) seated alongside a student with an accessible learning tablet.
5. `role-specialist.svg` (`SPECIALIST`): Clinical specialist (speech therapist / psychologist) with diagnostic clipboard and therapy aids.
6. `role-institution.svg` (`ORGANIZATION`): Architectural academy facade with collaborative team silhouettes.
