# ANEI v3.3 — UI/UX redesign

This redesign applies the UI/UX Pro Max workflow to the existing ANEI platform without changing backend contracts. It rejects the automatically generated child-oriented system and establishes a professional blue/slate, accessibility-first design system.

Benchmarks are used as principles, not copied layouts: strong catalog discovery and credentials (Coursera/edX), continue-learning and goal orientation (LinkedIn Learning), progress/path clarity (Pluralsight), and restrained editorial hierarchy (MasterClass).

The implementation intentionally adds no UI dependency. Existing server components, auth, RBAC, payments, Drizzle schema, migrations, API routes, and standalone deployment behavior remain unchanged.
